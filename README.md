# Legit Medicament

Welcome to the official repository for the **Legit Medicament** website. This is a modern, responsive static web application built to showcase our premium pharmaceutical and nutraceutical products.

## Overview
Legit Medicament aims to provide high-quality healthcare products manufactured under WHO GMP certifications. The website reflects our commitment to innovation and well-being with a trustworthy and professional design.

## Technologies Used
- **HTML5**: Semantic structure for clear accessibility.
- **CSS3 & Bootstrap 5**: Modern responsive design featuring CSS variables, glassmorphism, flexbox/grid layouts, and micro-animations.
- **JavaScript**: For interactive components like the mobile navigation toggle and dynamic footer dates.
- **Google Fonts**: Utilizing 'Poppins' for a clean, geometric, and modern typographic feel.

## Running Locally
To preview the website locally:
1. Clone this repository.
2. Open `index.html` in your preferred web browser.
3. Alternatively, you can use a local development server (e.g., `npx serve` or VS Code's Live Server) to serve the files.

## Project Structure
- `index.html` - The main entry point and homepage of the website.
- `styles.css` - Custom styles overriding and extending default Bootstrap components.
- `script.js` - Client-side scripts.
- `images/` - Contains all product images, background assets, and company logos.

## Design Highlights
- **Premium Aesthetics**: Medical blue themes combined with clean whites to instill trust.
- **Dynamic Interactions**: Hover effects on product cards and floating animations to keep the interface engaging.
- **Mobile-First Responsiveness**: Ensuring the site looks perfect across phones, tablets, and desktops.
